# College Assignment Tracker

## Project Description

College Assignment Tracker is a simple Python based command-line project.

It helps students in managing their college assignments by adding, viewing, searching, editing, completing and deleting assignments.

## Features

- Add a new assignment
- View all assignments
- Mark an assignment as completed
- Search assignments by name or subject
- View pending assignments
- View progress report
- Edit an assignment
- Delete an assignment

## Requirements

- Python 3.x
- No external libraries are required

## How to Run

1. Install Python 3.x on your computer.
2. Download or clone this project.
3. Open the project folder.
4. Run the program using:

python main.py

## How to Use

After running the program, a menu will be displayed.

Enter the number of the required option and follow the instructions shown by the program.

The available options are:

1. Add Assignment
2. View Assignments
3. Mark Assignment Complete
4. Search Assignment
5. View Pending Assignments
6. Progress Report
7. Edit Assignment
8. Delete Assignment
9. Exit

## Data Storage

Assignments are stored temporarily while the program is running.

The data is not permanently stored after the program is closed.
